# .github — org-wide defaults

Default **issue templates** inherited by every repository in this account that
does not define its own `.github/ISSUE_TEMPLATE/`:

| Type | For | Emphasis |
|------|-----|----------|
| **Issue** | a defect / problem | observed-vs-expected, repro, minimal fix |
| **Task** | committed work | goal, parent anchor, testable AC, MECE breakdown, DoD |
| **Idea** | a proposal | problem, rough approach, value-vs-cost, open questions |
| **Incident** | an operational failure | impact, timeline, root cause, rule-outs, follow-ups |

A repo can override any of these by adding its own template of the same name.
